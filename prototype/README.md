# Test prototype

A small static app that reads `data/synthetic/` (generated by `scripts/generate.py`)
and renders the three explanation variants from `mockups/` against real data, with
a test-harness control bar for jumping between participants/content sets/variants
that the real Latin-square study wouldn't expose.

This is a test harness, not the Session 2 build: it's useful for checking the
generated content looks right in context, not for running the actual study (no
logging, no fixed per-participant variant lock-in).

## Running it

Fetching local JSON needs an http:// origin, not file://. From the repo root:

```
python3 -m http.server 8000
```

Then open <http://localhost:8000/prototype/index.html>.

## Files

- `index.html` — participant picker. Lists P1-P9, D0, and W0 (warm-up) with
  their top skills (for P1-P9/D0 — the main skill of each of their 3 content
  sets).
- `app.html` / `app.js` — the main recommendation + explanation view. The grey
  dashed bar at the top (participant / content-set / variant selectors, a
  "show report_ids" checkbox) is test-only scaffolding, not part of the real
  UI. Picking W0 switches to the simpler warm-up layout (no badge/explanation/
  report — spec §9).
- `render.js` — the actual rendering of the three variants plus W0's simpler
  layout (shared with `../pilot/`, which is a stripped-down, D0-only,
  forward-only build of this same prototype for running a pilot session — see
  `../pilot/README.md`).
- `data.js` — fetch + normalization helpers. Every participant's three
  content sets, including D0's, are each an independent file
  (`data/synthetic/sets/<ID>-C<n>.json`) with no course repeated across
  C1-C3 -- D0 used to be exempt and kept one shared-list file, but that was
  removed since a real pilot session can't reuse the same courses round to
  round.
- `styles.css` — tokens and classes lifted from the mid-fi mockups' inline styles.

If you change `scripts/roles_data.py` or re-run `scripts/generate.py`, just
reload the page — `data.js` fetches with `cache: "no-store"`, so nothing here
goes stale across a regenerate.
